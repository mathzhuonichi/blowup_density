## Findings

### 1. `ATTEMPTS` trap 3 is wrong: `Set.Ico_subset_Ico_right` **does** exist — *severity: medium (record honesty)*

`research/R42/ATTEMPTS_SOL_SHORTER.md`, "Traps" item 3, states:

> **`Set.Ico_subset_Ico_right` / `Set.Ioo_subset_Ioo_right` do not exist** in the
> `Set` namespace in this Mathlib (`v4.34.0-rc2`); only the `Finset` versions do.

Both exist and both work as drop-ins here:

```
@Set.Ico_subset_Ico_right : ∀ {α} [Preorder α] {a₁ a₂ b : α}, a₂ ≤ a₁ → Set.Ico b a₂ ⊆ Set.Ico b a₁
@Set.Ioo_subset_Ioo_right : ∀ {α} [Preorder α] {a₁ a₂ b : α}, a₂ ≤ a₁ → Set.Ioo b a₂ ⊆ Set.Ioo b a₁
```

and `Set.Ico_subset_Ico_right hST.le : Ico 0 S ⊆ Ico 0 T`,
`Set.Ioo_subset_Ioo_right hST.le`, `Set.Ico_subset_Ico_right (by linarith) :
Ico 0 T ⊆ Ico 0 (T+δ)` all typecheck (`/tmp/r42rev/TrapCheck3.lean`, exit 0).

**Root cause, and the lesson that should replace the trap.** They are *not
declared* in Mathlib's source under that name — they are generated by `@[to_dual]`
from `Set.Ico_subset_Ico_left` / `Set.Ioo_subset_Ioo_left`
(`Mathlib/Order/Interval/Set/Basic.lean:281-290`, with the `to_dual_name_hint Left
Right` directive just above). A source `grep` for `theorem Ico_subset_Ico_right`
therefore finds only the `Finset` copy — which is exactly the conclusion ATTEMPTS
drew. **`to_dual`-generated names are invisible to source grep; `#check` is the
only reliable existence test.** That is a genuinely useful lesson and belongs in
`logs/LESSONS.md`; the current wording asserts the opposite and will cost the next
lane the same round-trip.

*No code change needed*: the committed `Set.Ico_subset_Ico le_rfl hST.le` is
correct and perfectly idiomatic. Only the ATTEMPTS entry is wrong.

## Statement fidelity — can a wrong implementation satisfy it?

**No.** The conclusion is
`∃ w : ClassicalSolutionR ν a gε S, w.velocity = u ∧ w.pressure = p`. The two
conjuncts pin the witness's fields to the *inserted* pair, so the reference
restricted to `[0,S)` is not a legal witness unless `u = ref.velocity` outright;
and `ClassicalSolutionR ν a gε S` bundles `initial = a`, `momentum … = gε (t,x)`
(against the **inserted** force), `sobolev` and `pressure_gradient`, none of which
can be met vacuously. The horizon guard `0 < S < T` is strict on both sides, as
lane 075 requires and as the paper's "at each `t<T`" wording gives
(`04-whole-space.tex:37, 53`); horizon exactly `T` is neither claimed nor needed.
Hypotheses mirror the API fields one-for-one with no strengthening: `hδ` is used
(for `Ico 0 T ⊆ Ico 0 (T+δ)`), `ht₁`+`hhist` feed `exists_datumPath_of_localized`,
`hvsupp` feeds the `sobolev` clause and `hpsupp` the `pressure_gradient` clause —
no dead hypothesis, no unused strength.

Paper check: `04-whole-space.tex:32-38, 53` — the inserted pair is a solution with
unchanged initial value and history (`u_ε = v` for `0 ≤ t ≤ T − 2ε²`), velocity
difference supported inside `B` at every `t < T`. The Lean hypotheses transcribe
these; `t₁` abstracts `T − 2ε²` and its positivity comes from `eps_time`'s
`2ε² < min(T,δ)`, one `min_le_left` + `linarith`.
