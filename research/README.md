# Exploratory work

Keep source comparisons, attempted routes, counterexamples and blocked
interfaces here, in English and organized by task ID. An exploration record
must distinguish a proved result, conditional implication, candidate and
unresolved gap. Cite exact versions and theorem locators.

This directory is not a Lean library and is never imported by acceptance tests.
Once a concrete statement has been reviewed, place its versioned contract in
`verification/Contracts/` and its implementation in the formalization library.
Do not commit build caches, numerical bulk output or copied private credentials.
