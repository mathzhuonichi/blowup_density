## Goal (unit B3; M–L)

1. **Barrier lemma.** Given `c, C > 0`, `K₀ ≥ 0` (the H¹ datum bound), `F ≥ 0` (the force bound): there is `d > 0` and `Ybar` (explicit: e.g. `d := 1/(4C(1+K₀)²)`-type, `Ybar := 2(1+K₀) − 1` — choose and prove) such that for every `t₀` and every `Y : ℝ → ℝ` continuous on `Icc t₀ (t₀+S)`, differentiable on `Ioo t₀ (t₀+S)` with `Y ≥ 0`, `Y t₀ ≤ K₀`, and every `Z ≥ 0` with `Y' + c Z ≤ C (1+Y)³ + C F` on `Ioo t₀ (t₀+S)` where `S ≤ d`: `Y ≤ Ybar` on `Icc t₀ (t₀+S)` (comparison with the ODE `y' = C(1+y)³ + CF`; a Grönwall/comparison argument — Mathlib's `image_le_of_deriv_right_lt_deriv_boundary` / `ODE_solution_unique`-style lemmas or a direct maximal-time argument).
2. **Integrated dissipation.** Under the same hypotheses, `∫_{t₀}^{t₀+S} Z ≤ (K₀ + C(1+Ybar)³ S + C F S)/c` (integrate the inequality; `Z` integrable on the compact interval is a hypothesis or follows from continuity — state which).
