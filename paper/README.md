# Manuscript files

`blowup_density.tex` is the build entry point. The five main sections and two appendices are
maintained separately in `sections/`. `references.tex` contains the single shared
bibliography, ordered alphabetically by author. `Makefile` writes the compiled PDF
to `../output/pdf/blowup_density.pdf`.

The source snapshots in `originals/server/` and `originals/local/` are preserved
unchanged. Make editorial changes in the merged section files. The reference
labels retained from the original articles support the theorem correspondence in
`../logs/THEOREM_CORRESPONDENCE.md`.
