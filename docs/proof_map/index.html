01 / WHAT IS PROVED

临界线以下，爆破力可以任意接近给定的力

第 4 节 · 全空间 ℝ³。论文定理 4.1–4.7 研究：改变外力，能否让流体在有限时间内出现速度无界的奇性？在光滑外力类的相对 L¹ₜHˢₓ 拓扑中，从零初值出发，会在给定 T 之前或当时失去正则性的外力是稠密的，当且仅当 s < 1/2；这表示可在积分范数中任意接近任何给定外力，不表示力的峰值很小。对任意固定光滑初值，临界线以下也有稠密性。论文还给出 L²ₜHˢₓ 的阈值 −1/2。直观上，把一个在 T 爆破的“小包”缩小，先修正背景、挖出一个局部空位，再精确放入：临界线以下，所需的力改动趋于零；临界处的小力正则性则给出反向障碍。标签：thm:Rmain、thm:Rinsert、prop:Rcritical1/2、cor:Rclasses、prop:Renergy、thm:Rgrid。论文原陈述意译：paper/sections/04-whole-space.tex:7–16、31–41、82–89、136–163、194–232、297–320。此处讲论文目标；每份 Lean 合同的实际边界见台账。

第 3 节 · 环面 𝕋³。把空间想象成对面粘合的周期盒子，同样的 L¹ₜHˢₓ 临界线是 1/2：固定初值时临界线以下稠密；零初值时得到“当且仅当”。全空间的小包要先局部化，再周期化；缩放、无散度修正和局部插入将它放进光滑背景。正则参考解附近能安排恰在 T 爆破；一般的稠密性只要求不晚于 T，不能混为一谈。后续还研究边界内插入、多处奇性、远离端点的变化和保守力。标签：thm:main、cor:nondensity、prop:density、prop:critical、thm:insertion、lem:correction、prop:scaling、cor:boundary、prop:affine/multiple/conservative。论文原陈述意译：paper/sections/03-torus.tex:6–20、122–139、218–242、287–307、349–356、383–389、506–516、587–590、632–665、668–734。边界与修正的 owner 待决限制单列展示。

为什么先有 Spec？

Lean 能排除无效证明，却不能判断形式化者是否挑错了目标。每个节点先由两个互不可见的草稿从论文独立转写，再把量词、端点、范数和定义域差异写进 COMPARISON.md / RECONCILIATION.md。这是“陈述保真”的人工审查边界。

为什么再冻一层 Contract？

canonical proof 可以重构、改名或换实现；冻结合同只保留外部承诺。普通定义由 rfl 桥钉住，定义一漂移桥就不再通过。Lean structure 不能跨两份定义用 rfl，因此用逐字段双向转换和往返引理，不假装两种归纳类型相同。

门禁拒绝什么？

合同 import 有白名单；旧 V1 和测试不得被静默修改；Tests 在 warning-as-error 下检查具体绑定及完整公理闭包；注册脚本核对 id、版本、模块与声明。负向 mutation probe 刻意改坏端点或量词，确认测试会真的失败。
